# Плагины порта

Бывшие встроенные пункты меню сообщения, вынесенные в плагины. Приложение показывает этот список
в каталоге плагинов рядом с каталогом [FullGram/FullGram](https://github.com/FullGram/FullGram).

После правки `plugin.fullgram.js` пересчитайте `sha256` и `size` в `index.json`: приложение не установит
файл, который не совпадает с каталогом.
