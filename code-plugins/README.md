# Плагины порта

Бывшие встроенные пункты меню сообщения, вынесенные в плагины. Это примеры
код-плагинов: приложение больше не показывает встроенный каталог, поэтому файл
устанавливается вручную через «Плагины → +».

Первый плагин — `chat-info/plugin.fullgram.js` («Инфа о чате»). Он добавляет пункт в
меню сообщения и показывает количество сообщений, кружков и голосовых, самые частые и
редкие слова, даты первого и последнего сообщения.

После правки `plugin.fullgram.js` пересчитайте `sha256` и `size` в `index.json`:
упаковщик и проверки CI не примут файл, который не совпадает с индексом.
